# grc103-phishing-simulation-metrics
# Phase 1 - Cybersecurity Risk Analysis

## Overview
This lab exercise analyses phishing campaign outcomes and evaluates the financial impact of cybersecurity controls.

## Objectives
- Assess phishing campaign effectiveness
- Calculate expected credentials stolen
- Estimate annual loss expectancy (ALE)
- Evaluate MFA implementation ROI
- Evaluate Security Awareness Training ROI
- Prioritise security controls based on risk reduction and financial benefit

## Key Findings

### Campaign Analysis
| Campaign | Financial Exposure |
|-----------|-------------------|
| A | $391,500,000 |
| B | $652,500,000 |
| C | $326,250,000 |

### Security Controls

| Control | Cost | Risk Reduction | ROI |
|----------|-------|---------------|------|
| MFA Implementation | $90,000 | $651,847,500 | 7241.75% |
| Security Training | $100,000 | $391,500,000 | 3914.00% |
